# MemoDams — Personal Cloud Vault & Diary

MemoDams is a personal digital vault and diary web application built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, **shadcn/ui**, **Genkit AI**, and **Firebase**.

Developed by **Ayoola Damisile A**.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Setup
Copy the example environment file:
```bash
cp .env.example .env.local
```
Or simply attach a new native Firebase project when importing into Google AI Studio / Project IDX / Firebase App Hosting.

### 3. Run Locally
```bash
npm run dev
```
Open [http://localhost:9002](http://localhost:9002) in your browser.

### 4. Typecheck
```bash
npm run typecheck
```
